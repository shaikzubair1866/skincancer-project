About DermaAI Architecture

Deep Learning & Explainable Artificial Intelligence for Dermatological Diagnostics

3-Model Ensemble (B0 + ResNet-50 + InceptionV3)

Our production classification engine combines EfficientNet-B0, ResNet-50, and InceptionV3 deep CNN architectures with 5-View Test-Time Augmentation (TTA). This configuration achieves 91.17% Test Accuracy, 90.70% Validation Accuracy, 0.8780 Macro F1, and 0.9897 Macro ROC-AUC across 1,484 untouched test images.

Patient-Level Split Integrity

To eliminate data leakage, the 10,015 HAM10000 dataset images were grouped strictly by lesion_id before split allocation into 70% Train, 15% Validation, and 15% Test splits.

Grad-CAM Visual Heatmaps

Gradient-weighted Class Activation Mapping computes gradients of the top predicted class score with respect to the final convolutional feature layer of EfficientNet-B0, generating 2D heatmaps overlaying key lesion regions.

Oracle DB Security

User sessions are signed with 24-hour JWT tokens and bcrypt password hashing. All prediction transactions are stored in Oracle SQL tables with parameterized queries.
